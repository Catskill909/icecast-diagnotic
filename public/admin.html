Backup & move

One file holds everything this monitor knows: the stations, the incident record, the listener history and the settings. Use it to keep a backup, or to move the monitor to a different server.

The file contains the alert email addresses, because they are part of a station's settings. Passwords are not in it — those live outside the data folder — but treat the file as you would a contact list rather than a spreadsheet.

Download a backup

Nothing on the server changes. Keep the file somewhere safe — it is the only copy of the incident history if the server is lost.

Restore from a backup

This replaces everything currently on this server. You will see exactly what is in the file before anything is changed, and the current data is renamed aside rather than deleted.
